# SEO計測計画（2026-10）

## 現在地

詳細ページ、トップの導線、`app-intro.html`の検索結果向け文言などの改善はProductionに公開済み。公開後の効果は未判定。比較基準はユーザー提供のSearch Consoleエクスポート（2026-10-03取得、日次の最終行は2026-09-29）で、直近の公開変更より前の期間を含む。数値・検索語の一覧は公開リポジトリには置かない。

## 同じ条件で比較する

1. Search Consoleでプロパティ`https://donomana.jp/`、検索タイプ「ウェブ」を選び、期間、検索結果のクリック数・表示回数・CTR・平均掲載順位を記録する。
2. 対象ページは、トップ、`app-intro.html`、SST・すごろく・なぞり書き・ひらがな・レジ・時計などの詳細ページ、`about.html`、`philosophy.html`を固定する。URLは完全一致で絞り、旧URLと新URLの役割も別に確認する。
3. 端末（モバイル、PC、タブレット）を分け、必要なページについてページと端末で絞ってから「検索キーワード」を見る。端末の合計、ページの合計、検索語の合計を独立に眺めるだけでは交差部分の傾向は分からない。
4. 指名検索と非指名検索を分ける。匿名化された検索語は一覧に現れないため、検索語行の合計を全体の合計とみなさない。表示回数が小さい行のCTR変動は過大評価しない。
5. 公開日を挟まない同じ長さの期間で、ページと端末ごとの表示回数、クリック数、CTR、平均順位を並べる。比較候補は2026-09-01〜09-28と2026-10-07〜11-03の各28日。Search Consoleの確定データが揃い、実際の公開日との前後関係を確認してから採用する。季節性、検索需要、順位、検索結果の見え方なども併記し、CTRだけで因果を断定しない。

## 次の確認と判断

- 2026-10-09を目安に、公開後の表示・インデックス・対象URLを初回点検する。これは改善効果の判定日ではない。
- 2026-11-04以降、比較期間のデータが揃ってから28日比較を行う。数値を見て、タイトルと説明文、導線、実際のモバイル操作性のどれを次に直すか決める。
- Search Consoleの最新データの取得には当該プロパティへのアクセスが必要。2026-10-03のエクスポートだけで公開後の成果を報告しない。
- 生徒のiPadでの軌跡確認、およびVoiceOver・Blue2・Tobii等の実機確認は別のユーザー確認事項。SEO計測の完了をもって実機確認済みとはしない。

## 引き継ぎ

この文書は計測手順であり、検索データそのものではない。比較時には取得日、期間、フィルタ、対象URL、最新`main` SHA、公開日、判断根拠を非公開の作業レポートに記録する。結果に基づくページ修正は新しい専用Phaseで行い、Production公開には別途レビューを要する。
