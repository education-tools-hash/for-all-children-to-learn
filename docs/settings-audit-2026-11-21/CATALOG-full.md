対象: production commit 7218d8f の凍結コピー（読み取りのみ）。行番号は各ファイルのもの。
凡例: 【事実】＝コードで確認した事実、【評価】＝監査者の所見。

## 6アプリ共通の前提（generate.js が差し込むブロック）

- 【事実】全6アプリに `<!-- a11y-panel: 自動挿入 (generate.js) -->` がある。画面右下に丸い「⚙」ボタン（#donomanaA11yBtn、aria-label「アクセシビリティ設定」）。開くと「⚙ アクセシビリティ設定」パネル（例 `janken-app.html:1155-1418`）。
  - 中身: 「🎨 表示モード」通常／ハイコントラスト、「🔤 文字の大きさ」標準／大／特大、「🔊 選択・タップの読み上げ」オフ／オン、「↺ すべてリセット」。
  - 保存: localStorage `donomana-a11y-contrast` / `donomana-a11y-font` / `donomana-a11y-sr`（`P='donomana-a11y-'`、`janken-app.html:1194,1206,1212,1234`）。全アプリ共通キーなので、1つのアプリで変えると他アプリにも効く。
  - 既定値: contrast=normal、font=normal、sr=オフ（`janken-app.html:1413-1415`）。
- 【事実】tokei 以外の5アプリでは、このパネルの一番上に「🔧 このアプリの詳細設定を開く」（#donomanaSettingsProxy）がある。押すとアプリ自身の設定ボタンを代わりにクリックする。アプリ自身の設定ボタンは generate.js が差し込む CSS で見えなく・押せなくされている（opacity:0 か display:none ＋ pointer-events:none、tabIndex=-1、aria-hidden）。
  - そのため、実際の入口はどのアプリでも「右下⚙ → 🔧 このアプリの詳細設定を開く」の2段階になる。
- 【事実】右上には「がめんをロック」と「⛶ 全画面表示」の2ボタン（lock-fs-btn ブロック）、左上には「どのまな トップページへ戻る」（home-btn）がある。右上の「❓ つかいかた」（#donomanaHelpBtn）は手書きで追加されたもので、janken と tokei にしかない。
- 【評価】文字サイズ・ハイコントラスト・読み上げが、共通パネルとアプリ側設定の2か所にある。文字サイズは janken / okane / schedule / timetable でアプリ側→共通側へ渡す同期処理がある。ハイコントラストと読み上げには同期処理がなく、別々の仕組みのまま並んでいる。
