1操作方法から探す

どのように操作しますか？　あてはまるものを選んでください。

👆画面に直接触れる 🔘外部スイッチを使う 👀視線で操作する 🤔どの方法が合うかわからない

2こんなことで困っていませんか？

操作の様子から選んでも大丈夫です。障害名や診断名で決める必要はありません。

複数の指で画面に触れてしまう→ 画面端を触ってホーム画面へ戻ってしまう→ 他のアプリへ移動してしまう→ 狙った場所を押すことが難しい→ 直接タッチが難しい→ 手・足・頭など一部の身体動作なら比較的安定して行える→ 視線を向けることを操作に利用したい→

3直接タッチで使う

画面に直接触れて操作する、どのまなの基本的な使い方です。多くのアプリは、大きく押しやすいボタンで誤タップを減らす工夫をしています。

手や指を画面に伸ばすこと自体が難しい場合や、狙った場所を一本指で押すことが難しい場合は、外部スイッチや視線入力も選択できます。また、複数の指で触れてしまう・意図せず他の画面に移動してしまう、といった困りごとには、次の「誤操作を防ぐ」の設定が役立ちます。

4誤操作を防ぐ

3つの機能は役割が異なり、どれか一つで足りるものではありません。お子さんの実態に応じて、組み合わせてお使いください。一律に利用を求めるものではありません。

🔒 どのまなの画面ロック

どのまなの教材内で、設定変更や意図しない操作を減らすための機能です。教材画面の🔒ボタンから使えます。

📱 iPad / iPhone「アクセスガイド」

端末を一時的に1つのアプリへ制限するためのApple公式のOS機能です。ホーム画面や他アプリへの意図しない移動を減らせます。どのまなの画面ロックとは役割が異なります。

🤖 Android「画面の固定／アプリ固定」

1つのアプリを画面に固定できるAndroid標準機能です。他アプリへの意図しない移動を防ぎやすくなります。

OS側の固定機能とどのまな画面ロックは、併用できます。 どちらか一方だけで十分な場合もあれば、両方使うことでより安心できる場合もあります。お子さんの実態に応じてお選びください。

iPhone / iPad アクセスガイドについて

1つのアプリに利用を制限できること、ホーム画面や別アプリへの意図しない移動を減らせること、タッチできる範囲の一部を制限できることなどが特長です。具体的な設定手順（設定アプリでの操作、パスコード／Face ID／Touch IDの設定、セッションの開始・終了方法など）は、OSのアップデートで変わることがあるため、Apple公式サポートページをご確認ください。

Apple公式: アクセスガイドの使い方↗（外部サイト）

Android 画面の固定／アプリ固定について

1つのアプリを画面に固定し、他アプリへの意図しない移動を減らせる、Android標準の機能です。端末のメーカーやOSのバージョンによって、「画面の固定」「アプリ固定」など名称や設定場所が異なる場合があります。Pixel以外のSamsung・Lenovo等の機種でも、設定アプリ内のセキュリティ関連の項目にあることが多いですが、断定はできませんので、お使いの端末のメーカー・Google公式情報をご確認ください。

5外部スイッチで使う

スイッチとは、1回のボタン操作（押す・触れる・動かす等）で画面の操作を行うための入力機器です。画面を直接タッチすることが難しい場合でも、手・足・頭など、比較的安定して動かせる身体部位でスイッチを操作する方法があります。

「この子にはスイッチが向いている」といった断定はできません。あくまで選択肢の一つとしてご紹介します。

代表例: AbleNet Blue2

Blue2は、Bluetoothで接続できる外部スイッチで、1台で2つのスイッチ入力（White／Orangeの2ボタン）を利用できます。iPad / iPhoneの「スイッチコントロール」機能と組み合わせて使うことができます。

Bluetoothのペアリング方法やモードの切り替え、iPad / iPhone側の詳しい設定手順は、以下の公式情報をご確認ください。

AbleNet公式: Blue2のペアリング方法↗（外部サイト） Apple公式: スイッチコントロールの設定↗（外部サイト）

1スイッチ・2スイッチの基本的な考え方

🔘 1つのスイッチ

自動的に選択候補が移動し、目的の場所でスイッチを押す方法（自動走査）などがあります。

🔘🔘 2つのスイッチ

「次へ進む」と「決定する」のように、役割を分けて操作する方法（手動走査）などがあります。

これは基本的な例であり、最適な設定は児童生徒によって異なります。走査速度なども、お子さんのペースに合わせて調整してください。

6視線で使う

直接タッチが難しいが、対象へ視線を向けられる場合、視線入力も選択できます。

必要なもの

視線を検出する機器（例: Tobii Eye Tracker 5）と、視線をマウスポインターの動きに変換するソフト（例: 見るマウス）が必要です。どのまな自体は追加のインストール不要で、ブラウザでそのまま使えます。

⚠️Tobii Eye Tracker 5に関する重要な注意

Tobii Eye Tracker 5は、Microsoftが公開しているWindows標準「視線制御（Eye Control）」の対応機器一覧には含まれていません。Microsoft公式の対応機器一覧には、Tobii Eye Tracker 4C・Tobii EyeX・Tobii Dynavox PCEye Plus／PCEye Mini／PCEye Explore・Tobii Dynavox EyeMobile Mini／EyeMobile Plus・Tobii Dynavox I-Series+・EyeTech TM5 Mini等が掲載されていますが、Eye Tracker 5はこの一覧に含まれていません。また、TobiiはEye Tracker 5をゲーミング向け製品として位置づけています。

どのまなでは、「Tobii Eye Tracker 5と『見るマウス』等を組み合わせた利用例」としてご紹介します。医療機器・専用の支援機器としての性能を保証するものではありません。なお、障害のある方向けの正式な視線入力装置（Tobii Dynavox PCEyeシリーズ等）も別に存在します。特定の製品の購入を強く推奨するものではありません。

どのまなでの利用例（全体の流れ）

Windows PC→ Tobii Eye Tracker 5→ Tobii Experience→ 動作確認／キャリブレーション→ 見るマウス 等→ 視線→マウスポインター操作→ Chrome／Edge→ どのまな→ 視線対応アプリ

どのまなを開く前に、Windowsのデスクトップ上で視線ポインターが正常に動くか確認しておくと、うまくいかないときの原因を切り分けやすくなります。

キャリブレーションのコツ（学校現場での補足）

実際に学習するときに近い姿勢（車椅子等の姿勢を含む）、画面との距離・位置、頭部の位置、眼鏡の有無、照明、姿勢の変化などによって、操作のしやすさが変わることがあります。医学的な評価や適合判定を行うものではありません。

見るマウスについて

Tobii Eye Tracker 5等から取得した視線情報を、マウスポインター操作へつなげるための選択肢の一つです。対応機器・バージョン等の最新情報は公式ページをご確認ください。

7うまく動かないとき

原因を段階的に確認できます。診断ではなく、確認の手順としてお使いください。視線入力のドウェル時間・走査に関する詳しい既存仕様は変更していません。

視線入力

視線そのものを取得できない → Eye Tracker接続 → Tobii側ソフト → キャリブレーション → 画面／姿勢
視線は取れているがポインターが動かない → 「見るマウス」等のポインター操作ソフトが起動しているか
ポインターは動くがどのまなが操作できない → ブラウザ → どのまな側の入力設定 → ドウェル時間 → ターゲットサイズ → 対応アプリか

外部スイッチ（Blue2）

Blue2が接続できない → 電源 → Bluetooth → ペアリング → モード（AbleNet公式Blue2ガイドも参照）
Blue2は接続済みだが反応しない → Switch Controlへの登録 → 入力割り当て → Blue2モード → どのまなアプリ側の対応状況

8どの操作方法が合うかわからないとき

これは簡易診断ではありません。障害名・診断名・発達年齢等から入力方法を決めるのではなく、操作の様子から選択肢を考えます。

画面へ手を伸ばせるが、狙った場所を一本指で押すことが難しい → 直接タッチ＋どのまな画面ロック＋アクセスガイド／Android画面固定＋大きな操作ターゲット
手・足・頭など一部の身体動作を比較的安定して繰り返せる → 外部スイッチも選択肢
直接タッチが難しいが、対象へ視線を向けられる → 視線入力も選択肢

「必ずこの方法が適している」と断定するものではありません。いくつかの方法を試しながら、お子さんに合った操作を見つけてください。

9印刷・PDF保存

校内研修や保護者説明、オフラインでの参照用に、このページを印刷・PDF保存できます。実際にはお使いの端末やブラウザ標準の印刷機能を使用します。

ボタンを押すと印刷画面が開きます。「PDFに保存」を選ぶと、PDFとして保存できます（iPad / iPhoneは共有シート→印刷→プレビューをピンチアウトでPDF化できます）。
