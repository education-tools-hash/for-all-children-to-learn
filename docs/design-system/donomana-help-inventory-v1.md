## Rollout優先順位トップ5

1. **bosai-app.html（Group D）** — チェックリスト・171番シミュレーション等の複雑機能を持つ防災アプリだが、Helpが皆無。初見の保護者・教員にとって非自明な機能が多く、Group D中で最優先。
