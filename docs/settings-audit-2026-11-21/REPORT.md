## 1. 全教材に共通する構造（最初に押さえるべき事実）

**設定の入口は、教材ごとではなく generate.js が全体で決めている。**

- generate.js が全アプリに共通の「アクセシビリティ設定」パネルを差し込んでいる（`<!-- a11y-panel: 自動挿入 (generate.js) -->`、`generate.js:1032-1366`）。
  - 入口は**画面右下の丸い「⚙」（48px、文字ラベルなし）**。aria-label／title は「アクセシビリティ設定」。
  - パネルの中身: 「🎨 表示モード（通常／ハイコントラスト）」「🔤 文字の大きさ（標準／大／特大）」「🔊 選択・タップの読み上げ（オフ／オン）」（一部アプリのみ）、「↺ すべてリセット」。
  - 保存先は localStorage `donomana-a11y-contrast` / `donomana-a11y-font` / `donomana-a11y-sr`。全アプリで共有される。
- `SETTINGS_PROXY`（`generate.js:974-1029`）に登録された **36教材**では、
  - 教材自身の設定ボタン（例「⚙️ せってい」）は CSS で**見えなくなる**（opacity:0 または display:none）。
  - 代わりに共通パネルの一番上に **「🔧 このアプリの詳細設定を開く」** ボタンが出る。
  - 例外: drawing-app は「👁 視線入力の設定を開く」、slideshow-sakusei と kyou-no-kiroku は「🔧 スイッチスキャン等の詳細設定を開く」。
- 登録されていない2教材（tokei-app、nazorin-print）は、教材独自の設定画面を持たない。tokei は画面上の「むずかしさ」と🔊だけ。nazorin-print は左パネルに常に設定が表示されている。
- 新規アプリ開発標準 v1.7 §7「設定入口一本化（REQUIRED）」が、この方式を正式な約束事として定めている（DOCS.md 1.1）。

→ 利用者から見た入口は、ほぼ全教材で同じ **「右下の ⚙（文字なし）を押す → 『🔧 このアプリの詳細設定を開く』を押す」の2段階** になる。

自動確認（ヘッドレス Chromium、file:// で対象 SHA の写しを開く、新しいプロファイル）の結果: janken・tyushi・kurabeyou・timetable の4教材で、上の手順どおりに教材の設定画面が開いた。tokei は 🔧 の行がない共通パネルだけが開いた（§5 参照）。

## 3. 横断所見

### 3-1（指示書 §3-8）同じ意味の設定で、名前が教材ごとに違う

**スキャンの速さ**（調べた範囲で名前は11種類）
- 「スキャンかんかく」「スキャン かんかく」「⏱️ スキャンかんかく」: hiragana, katakana, janken, timetable, okane, sugoroku, kimochi, suji, kurabeyou, dotchiga
- 「スキャン間隔」: nazori, tyushi, kyou-no-kiroku ／「スキャン間かく」: bosai ／「間隔」: yomikaki
- 「スキャンのはやさ」「スキャンの はやさ」: shiritori2, cup_game, ongaku, directions, schedule（「1スイッチ用」つき）
- 「スキャン速度」: register, time-timer, gaze-keyboard ／「スキャン速さ」: katachi ／「速度」: matching ／「ひかる はやさ」: ringo
- **値の向きもそろっていない**:
  - 多くは「秒（大きいほど遅い）」。
  - matching は「1〜5（大きいほど速い）」で、秒は表示されない。
  - bosai はスライダーの両端に「おそい／はやい」と書いてあるが、値と向きが逆。
  - katachi と time-timer は数値を表示しない。
  - janken と timetable では、同じ＋ボタンの読み上げ名が「おそく」と「ゆっくり」で違う。
- **既定値**: 1.0秒（gaze-keyboard）、1.4（katachi）、1.5（okane、shiritori2、cup_game、kyou、dotchiga、miru／mitsukete／junban は固定）、1.8（directions）、2.0（多数）、2.5（ringo）、実際は1.2（matching）。

**注視で決めるまでの時間**: 「ドウェル時間」（tyushi、mogura）、「けっていまでの じかん」（okane）、「決定までの時間」（kyou）、「見つめて決めるまでの時間」（kurabeyou ほか Multi-Input 系）、「みつめるじかん」（cup_game）、「みつづける じかん」（kimochi）、「停止判定時間」（gaze-keyboard）、「みつめてからはじまるまで」（drawing）。既定値は 0.9／1.0／1.2／1.5秒とばらつく。名前と既定値（900ms）を文書で定めているのは Gaze Standard v1.0 だけで、それに合っているのは Multi-Input 系と kurabeyou／katachi。

**設定画面そのものの呼び方**: 「アクセシビリティ設定」（共通⚙）、「詳細設定」（🔧）、「せってい」「つかいやすく せってい」「せんせいせってい」「せんせい用 せってい」「先生の設定」「教員モード」。1つの教材の中で3通りに揺れている例もある（mitsukete、junban、sawatte）。

**その他**
- ハイコントラストと文字サイズは、共通パネル版と教材独自版の2系統が並んでいる教材が多い（例: janken、timetable、hiragana）。教材独自の「ちいさい」は共通側に対応する値がなく、保存されない。
- 「ロック」も2種類が同じ画面にある（time-timer: 共通の「がめんをロック」と「せっていのロック（PIN）」）。

### 3-4 設定が子どもに届いていないと考えられる典型パターン（事実と評価を分けて記載）

1. **入口が2段階で、最初の段に言葉がない**
   - 事実: 36教材で、教材自身の「せってい」ボタンが消され、右下の文字なし「⚙」→「🔧 このアプリの詳細設定を開く」になっている。⚙ の名前は「アクセシビリティ設定」。
   - 評価: 先生には「見え方の調整」の入口に見えやすく、レベル・スキャン・音などの教材の設定がその奥にあることが分かりにくい可能性がある。
2. **ヘルプと画面が食い違っている**
   - 事実: 7教材が見えない入口を案内し、9教材は行き方を書いていない（3-3）。
   - 評価: ❓を読んでも設定にたどり着けない経路がある。
3. **変えた設定が次回に残らない**
   - 事実: 教材の設定を保存しない（×）のは10教材（yomikaki、shiritori2、janken、timetable、bosai、sugoroku、tyushi、cup_game、drawing、mogura）。一部だけ保存（△）は9教材。保存する教材でも「スイッチスキャンのON/OFF」は多くで保存されない（katachi、miru、mitsukete、junban、dotchiga、ringo、hiragana、katakana、suji、time-timer、gaze-keyboard など）。
   - 保存の操作にくせがある例: register は「閉じる」でだけ保存（Esc や背景のクリックでは保存されない）、ongaku は「💾 ほぞん」でだけ保存、slideshow はタブを閉じると消える。
   - 評価: 子どもに合わせて設定しても、再読み込みや翌日には既定値に戻る教材が多い。「どの子にも同じ既定設定のまま」になりやすい構造的な理由の1つと考えられる。
4. **名前・向き・既定値がそろっていない**（3-1）
   - 評価: 教材ごとに覚え直しが必要になる。
5. **試して確かめる仕組みが少ない**
   - 事実: 試せる仕組みがはっきりあるのは nazorin-print（A4プレビュー）、slideshow（中央プレビュー）、tokei（はやくためす）、sst（▶ テスト）、time-timer（試聴）、register（読み上げ速度の試し読み）、tyushi（背後のボタンにすぐ反映）くらい。
   - 事実: パネルを開くとスキャンや視線が止まる教材もある（bosai、kimochi、kurabeyou など）。その場合、パネルの中でスキャン速度や注視時間の効き方を確かめられない。
6. **ヘルプの分量に対して、設定の説明が少ない**
   - 事実: ヘルプは20〜190行あるが、設定の部分はおおむね数行。

### 3-5 要確認（コードの値と画面の値の食い違い、動作の疑い。詳細と根拠の行は CATALOG-full.md）

- matching: 速度スライダーは3（1.3秒相当）を示すが、実際の初期間隔は1.2秒。
- bosai: スライダーの「おそい／はやい」の表示が逆。ヘルプは「PIN を設定で変更できる」とあるが、PIN は '1234' 固定。
- kimochi: 全体リセット後にみつづける時間が1.5秒になる。視線の項目が欠けて「NaN秒」と表示される疑い。
- sst: 設定シートに閉じるボタンがなく、Esc も効かない。PIN 画面の案内先が実際（教員モード）と違う。
- ongaku: 先生画面を開いたとき、保存した値が「もどるボタンをロック」以外は表示に反映されない。
- kurabeyou／katachi: ヘルプの「視線とスキャンは同時にONにできない」と、コード（同時にONにできる）が矛盾。katachi は保存されたスキャン速度の範囲を確かめていない。
- register: 「アニメーションを減らす」が効いていない可能性。
- tokei: 🔊 は効果音だけを止め、「じこくを きく」の読み上げは止まらない（ヘルプの説明と違う）。
- yomikaki: 速さスライダーの値 0.85 が刻み幅に乗らない。見えない「せってい」タブがスキャン対象に入る可能性。
- shiritori2: 読み上げ速度の文言に誤字らしきもの（「さいこく」）。
- directions: 保存キー `appSettings` に接頭辞がなく、同じオリジンの他アプリとぶつかるおそれ。
- time-timer: PIN が保存されていても、再読み込み後はロックが外れた状態で始まる。
- tyushi: スキャンモードは見た目の点滅だけで、決定を絞り込まない。
- gaze-keyboard: 文字の大きさが保存の中身に含まれていない。
- 文書: help-inventory が古いまま（35件・未反映の表記）。Widget 設計書のリセットの記述が実装と違う。

いずれもコードを読んだうえでの疑いで、抜き取り照合の対象（§5）を除き、画面では確かめていない。
